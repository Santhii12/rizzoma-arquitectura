# Rizzoma Arquitectura — v0.4

Evolución de la web de Rizzoma hacia un portafolio editorial y comercial de estudio emergente. Esta versión incorpora la identidad personal de Juan José Quintero Tobón, mantiene la paleta de marca definida en la web actual y refuerza el sitio como práctica independiente de arquitectura y visualización.

## Ejecutar

```bash
npm install
npm run dev
```

Para validar antes de publicar:

```bash
npm run check
npm run build
npm run preview
```

## Identidad visual

- Verde oliva de marca: `#62614F`
- Crema de marca: `#F8EEDA`
- Monograma `RZM`
- Wordmark `RIZZOMA`
- Retrato de Juan José Quintero Tobón

## Despliegue

El proyecto queda preparado para despliegue automático en GitHub Pages mediante GitHub Actions. Mientras Rizzoma se revisa públicamente, la URL de prueba será la de GitHub Pages. Más adelante puede conectarse el mismo repositorio a Cloudflare Pages y al dominio definitivo del estudio.
